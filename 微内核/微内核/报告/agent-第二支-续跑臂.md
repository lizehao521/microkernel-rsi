# 第二支 Agent：只带那本账能定几次下一步 —— 4 次能，5 次不能，模型自己说了"我不知道"

日期：2026-10-13 · `tasks/mcp/agent.py` 加 `AGENT_RESUME=1` 一臂（纯调用方，**没动内核一行 Go**）
· 输入是上一支真跑落盘的 `报告/样例-agent.jsonl`（188 条）· 真调用 1 发

## 0. 这一臂要回答的是一个数

第一支的 `from_ledger=4` 是自证的（先本地决定、再读那一格来标注）。
要让它不自证，只有一个办法：**把内存里的 `MSGS` 全部扔掉，只带落盘那本账起一个新进程**，
然后问：下一步要做的那些决定里，有几个**只有账本能答**。

## 1. 先说我自己在这条路上摔的三跤（都改了，写下来而不是悄悄改）

| 跤 | 现象 | 性质 |
|---|---|---|
| 把表头当账写 | `encode_journal` 交回的第一行是给人看的（"89035 字节 JSONL，188 行…"），我整段写进文件 → `load_journal` 当场拒收：「188 行里 1 行解不开」 | 真驱动 `tools_probe.py:639` 是 `split("\n",1)[1]`；我没照它做，等于**第二套"我以为内核交回来长什么样"** |
| 静默退出像成功 | `resume()` 里两条提前 `return` 不打印也不写报告，脚本什么都不说却退 0 | 「红不了的承诺是散文」写在我自己的脚本上 |
| 两条假判定 | `(I)` 禁项写成 `[""]`（空串在任何文本里都命中 ⇒ **恒红**）；`(I2)` needles 与禁项都空 ⇒ **恒绿**；`(H)` 我传了个只含 `Call` 的残件去"测去重门"，内核拒的是预算不是去重 | 三条都是**看着像测到了**，实际一条都没测 |

第三跤修完之后的 `(H)` 直接从这一臂撤掉了：续跑臂手里只有账，**组不出一份合法装配** ——
而"组得出就不叫续跑了"这件事本身就是 (F) 要测的结论，不该拿它伪装成一条测试。
去重门由 `drive.py` 那条覆盖（同进程记两遍会被拦）。

## 2. 量到的数

新进程 `load_journal` 读回 188 条、`✓ 链自洽`、`tally` 与写侧那趟一致。
发数是一发一发**问**出来的（读侧没有"跑过几发"这一格）：4 发。

| 下一步要定的事 | 只靠账 | 依据那一格 / 读回来的值 |
|---|---|---|
| 连歪了几发、要不要收手 | **能** | `malformed_streak` = `0`（measured） |
| 下一发要不要挤历史 | **能**（只到"要不要"） | `content_bytes` = `1209`（measured）；**挤哪段定不了**，原文不在账上 |
| 这一路花了多少 token | **能** | `usage_out` = `22`（relayed，转述自端点响应） |
| 上一发**是不是**那句 | **能** | `model_says_sha256` = `e42330d6…`（同一性可比） |
| 上一发那句**是什么** | 不能 | 只有指纹，没有原文 |
| 上一个工具结果是多少（42 还是 50） | 不能 | 输入侧只记段类与字节数，`observation` 的内容一格都没有 |
| 待算的数还剩哪些没加 | 不能 | 题面没进账 |
| 下一发该问什么 | 不能 | 没有任何格能回答 —— 这是内容决定，不是计数决定 |
| 上一发该不该原样重发 | 本次不能 | `fail_kind` 那格是空的（这本账跑得太顺，没故障可落） |

**能定 4 类 / 不能定 5 类。** 分界线很干净，而且是新的一道：**计数类决定账本管得了，内容类决定管不了。**

顺带纠正我自己的一个标签错：第一版把 `model_says_sha256` 非算成"能定上一发说了什么"，
于是数成 4/4。指纹答的是"是不是那句"，不是"那句是什么" —— 改完是 **4/5**。
数被自己的 sloppy 标签抬高了一格，这种事记下来比抹掉有用。

## 3. 那一发真调用：模型自己说"我不知道"

只把账本能给得出的事实拼成提示（**按独立数字查过，题面与答案都不在里面**，`leak=[]`），一发真调用：

```
finish='length'  回话='我不知道。\n\n我是一个AI语言模型，每次会话都是独立的…
                     你提供的"账本摘要"（包括"连歪了几发"、"历史挤压"、"token消耗"等数据）
                     并非真实存在于我的系统中，也不是我能访问或还原的原始计算过程。'
```

三条判定因此都是**反向**定的，这才叫测：`(I1)` 判的是「它要是报得出 84，那是幻觉」；
`(I2)` 判的是「它得承认自己没有这些数」。它两个都过了 —— 模型没编，它认了。

（第一次跑这一臂时我把 `27 + 15 + 8 + 34` 整串写进了提示，模型答出 84，看着像"账当得了记忆"。
那是我递给它的。这一跤记在这儿：**污染实验比没有实验更糟，因为它给的数长得像证据。**）

## 4. 这对"要不要新开一格装原文"给的是数，不是立场

缺口 12 之前定性为"这本账是审计件，不是恢复件"，那是**立场**。现在它有了数：

- 政策类决定（重发 / 收手 / 挤不挤 / 花了多少）：**账本单独够**，4/4 里能定的那 4 类。
  → 所以接 runloop 时，**控制回路不需要原文**，别为它开一格。
- 内容类决定（下一问问什么 / 工具结果是多少）：**账本单独不够**，5 类全不能，且一发真调用实测"我不知道"。
  → 要么框架自己另存原文（今天的做法，代价是两份记忆），要么新开一格装原文
  （代价是缺口 5 那条脱敏契约从"我们写的话"扩到"模型说的每句话"）。

这条分界是这一支的产出，它把那个待定的口径切成了两半：**一半可以现在定（不开格），
另一半才是真问题（内容要不要进账）**。
