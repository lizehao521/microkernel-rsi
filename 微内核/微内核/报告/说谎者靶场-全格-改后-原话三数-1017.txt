== 自印分母 ==
分母=11 格（带出处档的格，来自 cells.go 的 measureCell 登记）；这一轮真跑到=11 格；装配不到=0 格
预检与落账**分歧**的格 = 0（#20 要的正是这个数为 0）
回话为空的臂 = 0（要 0；非 0 则上面所有读数不可信）
被拒的格 = 8；这 8 条拒收原话互不相同的有 8 条；回话里原样出现 snake 键名的 = 0 格；原样出现 JSON 字段名的 = 0 格；最长那句 49 字
一句实话（这一栏测的是内核原话的形状，与 #20 那次改动无关）：
  · 「两两不同」只证明**每格各说一句**，不证明那句话能把格对上 —— 把「分帧数」认成 chunks 需要人（或一张表），
    而内核里没有这张注册表：拒收文案是逐条规则手写在各 check 里的（如 input.go:339「token 那一格」），没有 per-cell 的中文名字段；
  · 所以我**不印**「点名 N/8」这种数 —— 那要我先造一份中文名单，等于把尺子换成我的话（#20 那轮立的规矩：分母不许是我挑的清单）；
  · 结构化归因那一半仍开着 = **#48**：回话里没有机器可读的格键名（snake 键名命中 0、字段名命中 0，两个数就是这一句的读数）。
