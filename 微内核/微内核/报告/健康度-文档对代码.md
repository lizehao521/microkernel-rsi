## 要改代码的（文档改不动，得动判据）

1. **隔离闸的分母混了一个量**：`isolate.go:336` 跑 `go list -deps ./...`。
   实读 `go list -deps .` = **116**（不含 `net/http`）、`./...` = **208**（含）。
   闸门印 208 而 README 说的是「本包每个 `.go` 文件」。
   后果：谁把 `net/http` 引进 `package kernel`，**两个读数都不会变**（208 里早就有），`越界 0 个` 照样 ✓。
   建议：拆 `DepsSelf` / `DepsTree` 两个分母，「越界」只对 `DepsSelf` 判定，`DepsTree` 只印分母。
2. **这张新检还没进任何闸门**：它现在是**手动一条命令**。漂了不会自己红。
   要它长期站岗，两条路：进 `kcheck`（纯 Go 侧，需要把解析表这件事搬进包外程序），
   或进 `kprobe`（多一根「跑 audit 脚本要求退出码非 0」的针）。**这条要定：文档一致性算不算内核的判据**——
   它守的不是代码行为，是仓库自己那条「不许漂」。
