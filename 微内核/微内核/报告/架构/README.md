# agentkernel 当前架构 · 一页说明

配套：`system-context.mmd`（边界视图）、`system-model.mmd`（内核内部组件）、`evidence.md`（逐条 sourceRef）。
范围：仓库现状，2026-10-13。图里每个节点都能在 evidence.md 找到它住哪个文件。

## 这个系统是什么

一个**只管"谁算的"的账本内核**，加一层能被 Agent 当工具调的外壳。
`kernel.go` 头部把定位写死了：调度、渠道、MCP 都不在这里 —— 那些已有商品化实现；
这一层只做一件别家没有的事：**每一条在代理之间流动的说法都带着"谁算的"，缺这一格就进不来**。

## 三层，方向是单向的

```
框架/调用方（Python: tasks/mcp/*.py，决定问什么、怎么装配、判定红不红）
      ↓ 只通过 10 个 MCP 工具名说话
外壳（Go: cmd/mcpkernel 转发；cmd/kcheck 自断言）
      ↓
内核（package kernel：出处三态 + 47 格 + 整发拒收 + 哈希链；不写盘、不 import net/http）
```

`isolate.go` 用 `go/ast` 读自己的源码来**证明这层依赖方向没被破**（不 `net/http`、不写盘），
这条不是文档承诺，是能跑的检查（`CheckIsolation`/`SelfIsolation`）。

## 关键关系

- **写侧有门，而且是双向互核。** 一发的输入侧 + 输出侧 47 格一起交，任一侧不自洽 ⇒ **整发拒收、两侧都不写、拒收另计一格**。
  本 session 撞出两次：一次我把 200 空响应记成正常收尾，一次 `protocol` 带着状态码 200。
- **落盘不在内核里。** `encode_journal` 只把 JSONL **字节**交回调用方，写盘是驱动干的；
  `load_journal` 让新进程把整本账顶回来，等价于"进程重启过一次"。
- **链只证明"写下来的没被动过"。** 所以 `CheckChain` 是三态（自洽 / 不符 / **核不了**），
  缺尾必须单独报，不许读成自洽 —— 内核不变量第 2 条。
- **闸是三层**：`go test` + `kcheck`（快）→ 慢闸 64 针（锚点是**精确源码文本**，源码一改就 ANCHOR-BAD）→ 格位表审计。
  当前基线：64 针全绿。

## 今天确实没有的那条边（这是这张图最想让你看见的）

**读侧出来的东西，没有任何一行代码据它改变下一步。**
两个真跑驱动里，`read_back`/`tally`/`verify` 全部落在**回合循环之后**的判定段：

| 驱动 | 循环体 | 最早的读侧调用 |
|---|---|---|
| `tools_probe.py` | `:356` | `:460` |
| `qa_loop.py` | `:263` | `:270` |

循环体里"下一发怎么装配"用的是本地 `if`（`if t["http_error"]`、`elif bad:`），一次都没问过内核。
`malformed_streak`、`Downgrade`、`ClampRounds`、被拒计数这些格**结构上已经在那儿了**，
但它们是事后描述，不是控制输入 —— 结构性证据（字段存在）不等于行为性证据（有人据它行动）。

所以：**内核今天矫正的是写账的人，不是模型的下一步。**
`declare_reader`（"声明我读了这一格"）这个工具也存在，真跑驱动里 0 次使用。
要把它变成"矫正 Agent 的头"，缺的不是格，是那条回边 —— 以及它住在哪一层（外壳？驱动？一个新的 runloop？），
这个位置目前**没有证据**，属于待定的架构决策，不是现状。
