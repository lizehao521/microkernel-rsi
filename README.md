# 微内核-RSI

在 [agentkernel 微内核](./微内核/微内核/README.md) 之上加一个**两代改进对账件**：
任何 RSI 生产者交两份代 manifest（上一代 / 这一代），`rsi` 包判「这次改进算不算数」，
判定与两份 manifest 一起锚进内核哈希链。

这是**冻结内核的仓外分支实验**，不是新内核：只在外侧加 `rsi/` 判据包和 `cmd/krsi/` CLI，
内核 48 键 / 49 格一格没动，RSI 循环本身不住在这里——本件对内是尺子，对外是对账底座。

## 怎么跑

在 `微内核/微内核/` 下：

```bash
go test ./...          # 全部判据（单元测试）
go run ./cmd/kcheck    # 闸门：逐节核，每个数由它自己印
```

前提 Go 1.27+；慢闸还要 Python 3。`kcheck` 看最后一行 `✓ 全部通过` / `✗ N 项没过`，
**以退出码为准**（非 0 = 有项没过）。

## 两代对账

```bash
go run ./cmd/krsi examples/g1.json examples/g2.json 报告.txt 账本.jsonl
```

退出码：`0=improved`（算数）`1=not_improved`（读数不支持）`2=refused`（点名哪条判据）`3=undecidable`（量不到，说理由）。

| id | 判 | 红的形状 |
|---|---|---|
| R1 | 结构自洽 | 缺格、缺席无理由、basis 不在档、代际不增 |
| R2 | 产物真变了 | 两代指纹集相同（同字节换标签） |
| R3 | 判据没放水 | loosened/removed、指纹变了没交 diff |
| R4 | 读数可判定 | estimated/model_says 冒充证据 |
| R5 | 改进为真 | 指标没严格变好；无分母比率 |
| R6 | 锚定可验 | 同一代不同 manifest/判定重记；链 Verify 不过 |

判定四态**不塌**：`refused > undecidable > not_improved > improved`（拒收不被「核不了」截胡）。
假改进五形（同字节换标签 / 判据放水 / model_says 当证据 / 无分母比率 / 判定恒等返回）
各配一根反臂，针表见 `微内核/微内核/tasks/probe/rsi_probe.py`。

- 内核总闸：`微内核/微内核/报告/报告-kprobe-重跑-1108.txt`；全量 `go test ./...` FAIL 0。

**要数就现跑 `kcheck` 或读报告件——这份 README 不维护会漂的数。**

## 证据边界

- 示例与测试走出来的绿 = **剧本绿**；真实 RSI 生产者 **NOT_RUN**，真模型端点 **NOT_RUN**（401 invalid_key）。
- 本模块判「读数支不支持改进声明」，不判产物质量本身；判据集由生产者交，R3 防放水、不防判据本来就错。
- 链证「写下来的没被动过」，不证「该写的都写了」（内核不变量 2）。
